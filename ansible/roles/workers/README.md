# Workers Role

## Purpose
This role joins `k8s-worker1` and `k8s-worker2` to the Kubernetes cluster.

## What It Does
- Reads the join command generated by the master.
- Executes `kubeadm join` on each worker node.

## Data Flow
1. The master role exposes a valid join command.
2. The workers role uses that command on each worker VM.
3. The kubelet on each worker registers the node with the control plane.
4. Once Flannel is running, the nodes become ready for workload scheduling.
