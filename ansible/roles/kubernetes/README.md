# Kubernetes Base Role

## Purpose
This role installs the base Kubernetes packages on all cluster nodes.

## What It Installs
- `kubelet`
- `kubeadm`
- `kubectl`

## Data Flow
1. The role configures the Kubernetes apt repository.
2. The packages are installed at pinned versions.
3. Package versions are held so the cluster stays reproducible.
4. The master role uses `kubeadm init` to create the cluster.
5. Worker nodes later join the cluster using the token generated by the master.

## Why this role matters
It ensures every node can participate in the cluster and that `kubectl` is available where needed for validation and automation.
